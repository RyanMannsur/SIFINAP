# SIFINAP

Projeto organizado com a pasta `fontes` na raiz, contendo:

- `fontes/backend` - backend Java/Spring Boot
- `fontes/frontend` - frontend Angular em TypeScript

## Frontend

O frontend usa Angular recente com Bootstrap, Material Icons e estrutura por:

- `features`
- `services`
- `components`
- `pages`
- `helpers`

Os componentes reutilizáveis foram reaproveitados do projeto OpenFeed.
